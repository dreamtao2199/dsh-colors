# PRD · DSH 主题系统（Celadon Studio）

| 项 | 内容 |
|---|---|
| 产品名 | 多彩Harness（包名 `dsh-colors`） |
| 插件标识 | `@local/dsh-theme-celadon` |
| 当前版本 | 0.9.9 |
| 文档状态 | 生效中（本文件是实现的验收基准） |
| 最后更新 | 2026-10-03 |

---

## 1. 背景与问题

DSH 自带「浅色 / 深色 / 跟随系统」三选一，配色不可定制，界面在长时间使用下缺少辨识度与个人化空间；多工作区并行时，无法从视觉上快速区分当前所处项目。

本插件在不修改 DSH 源码、不替换宿主组件的前提下，通过官方扩展点提供**配色、表面效果、自动切换、工作区区分、对话标注**五类能力。

## 2. 目标与非目标

### 2.1 目标

| 编号 | 目标 | 衡量方式 |
|---|---|---|
| G1 | 提供三套体系的成品配色（Pantone 年度色 / 中国传统色 / 莫兰迪高级灰），共 22 套 | 色板可见、可切换、切换即时生效 |
| G2 | 每套配色通过 WCAG 无障碍阈值 | 自动断言：正文对底 ≥7:1，次级/强调 ≥4.5:1 |
| G3 | 提供 14 种表面效果，**单一组单选**；效果与配色是**叠加**关系，不互相覆盖 | 每种效果可独立观察差异；切换配色不影响已有效果 |
| G4 | 支持按固定钟点自动切换（间隔 / 十二时辰二选一） | 行为可预期，锚点不漂移 |
| G5 | 支持按工作区绑定强调色 + 帧级色条标识 | 切换工作区时强调色随之变化 |
| G6 | 支持在对话正文中做视觉标注 | 加粗/行内代码/引用块随当前配色着色 |
| G7 | **不出现深色界面** | 任意偏好下底色均为浅色 |
| G8 | **不可导致宿主崩溃或卡顿** | 见第 6 节安全不变式 |

### 2.2 非目标

- 不修改 DSH 源码、不替换宿主组件、不注入到宿主 DOM 结构（仅使用官方插槽与样式表）
- 不提供深色主题（明确排除，非暂缓）
- 不做图片取色生成配色
- 不做多语言（当前仅中文）

## 3. 用户与场景

| 场景 | 期望 |
|---|---|
| 长时间阅读对话 | 低刺激配色、字号稳定、无闪烁 |
| 多项目并行 | 一眼分辨当前工作区 |
| 夜间/白天 | 到点自动切换，不需要手动干预 |
| 想换风格 | 一次点击换全局，不需重启 |

## 4. 功能需求

### FR-1 配色库（22 套，仅浅色）

- 分组：A · Pantone 年度色（4）、B · 中国传统色（14）、C · 莫兰迪高级灰（4）
- 每套提供 10 个官方 alias token；强调色由身份色**自动加深至 WCAG 4.5:1** 得出，不手工指定
- 提供「官方原色」位置：清空全部覆盖，回到宿主默认
- 验收：切换后正文/次级/强调对比度达标（自动断言）

### FR-2 表面效果（14 种，单一组单选）

**一组**，不再分「纹理」「材质」两个互斥组：8 张纸感/织纹贴图 + 6 种材质与交互类。

毛玻璃、渐变雾面、纤维、云絮、和纸、牛皮纸、亚麻、直纹纸、网点、扫描线、硬描边、焦点描边、浮层投影、描金滚动条。

- **展示顺序**：配色库与表面效果均按**字数升序 → 同字数按拼音**排列；「官方原色」与「无」作为"位置"固定排在最前（它们不是色板成员）

- **单选**：同时只允许一种；引擎层硬上限 1 个全屏层
- **与配色叠加**：效果只写行为类 token（不透明度、阴影、描边、滚动条、贴图背景），配色只写颜色类 token，两者互不覆盖；换配色不丢效果，换效果不丢配色
- 每种效果必须**可观察**：不可观察的效果一律不上架
- 毛玻璃定位为「磨砂」：表面不透明度 ≥0.75，模糊半径 ≤12px
- 贴图为 128×128 无缝 PNG（64 色量化），平铺接缝由 `_tools/verify-textures-celadon.py` 数值验收（见 §8）

### FR-3 作用范围（点缀强度三档）

克制（5 项）/ 标准（15 项）/ 张扬（20 项）。张扬档不得包含会破坏宿主几何形状的 token（如 `--dsw-corner-shape`）。

### FR-4 自动切换

| 模式 | 规则 |
|---|---|
| 关闭 | 不自动切换（默认） |
| 间隔 | 1 小时 / 1 天 / 1 周 / 1 月，锚定固定钟点（次日 06:00 / 下周一 06:00 / 次月 1 日 06:00） |
| 十二时辰 | 四段（默认卯时 05:00 / 巳时 09:00 / 酉时 17:00 / 亥时 21:00），每段时刻与配色可编辑；**名称取该段起始时辰** |

互斥：两模式不可同时启用。轮换集合默认全部 22 套。

**手动优先**：手动点选配色时**不关闭自动切换**，而是记下「手动优先到下一个时段边界」，到点自动交还给排程。此前的实现是手动点击即永久关闭自动切换——一次试探性点击就会静默丢失排程，已废弃。

### FR-5 工作区配色

- 每个工作区可绑定一套配色；未绑定时跟随全局
- 绑定模式：**仅强调色**（默认，底与面保持全局统一）/ **整套**
- 帧级顶部色条标识当前工作区；无信号时不渲染
- **点击全局配色时，清除当前工作区的绑定**（避免"改了全局却没生效"）
- 提供「全部跟随全局」一键清空

### FR-6 对话标注

对 Markdown 容器内的 `strong` / `em` / `blockquote` / 行内 `code` 应用当前配色的强调色与底纹。不修改渲染器、不新增语法。

### FR-7 会话状态指示

四态：运行中（旋转弧线）/ 等待审批 / 出错 / 已完成。默认**不显示**输入框下方的状态条；引擎仍采集信号以驱动工作区配色。

### FR-8 安全与诊断

- **安全模式**：一键停用全部绘制（含配色），可再次点击恢复
- **还原出厂设置**
- **诊断面板**：期望值 vs DOM 实际读回值（期望值 = 本插件刚刚写进样式表的那个值）、重绘次数、服务失败次数、全屏层数量、熔断状态、最近一次故障
- **「重新应用」**同时清除故障横幅；故障复发会立即重新记录

### FR-9 账号行（昵称 + 头像）

- 席位 `settings.launcher`（侧栏左下账号入口）；**不触碰左上品牌标志**
- 昵称 ≤24 字；头像上传 ≤1MB（转 data URL 存 localStorage），可单独清除
- **默认关闭**：关闭时**完全不注册**，官方账号菜单（含快速退出登录）原样保留；开启后在**更低优先级**上注册以替换官方行，停用即注销还原
- 头像超过 1MB 在载入时被丢弃；数据 URL 超过 700KB 时面板提示接近存储上限（localStorage 为唯一后端，见 §10）
- 存储写入失败（如配额用尽）**必须可见**：记为故障并显示在诊断区，而不是静默丢失

### FR-10 会话颜色标记

- 给**单个会话**手选一个颜色，会话行首出现 3px 竖杠；未标记的会话保持素净（不做"未读/运行中"自动染色——那会与宿主自己的状态点重复，且在长列表里变成花墙）
- 入口：会话行「…」菜单（官方席位 `sidebar.workspaces.session.menu.item`）与工作台列表
- 色板六色**全部由当前配色推导**（首两色为 brand 与其配套对色，其余为 brand 向固定色相混合），统一推到 **≥3:1**（图形对象非文本对比标准）且互不重复；无配色时用中性族
- 行绘制走**声明式 CSS**（`[data-session-id]`），不做 DOM 变更

### FR-11 主界面入口

- **侧栏底部快捷入口**：注册 `sidebar.footer.action`（order 9，紧邻「插件广场」`skillhub-plaza` 的 order 8），与它平分侧栏底部那一条
- 该席位 ownerProps 只有 `{ wide }`（无导航 API）→ 按钮自带动作：**点一下＝随机一套**；tooltip 写明当前配色；窄栏（56px）只留图标
- **不注册** `sidebar.panellist` + `main`：主导航里再放一个入口与设置页重复（0.9.10 移除）
- 完整设置页由 `settings.section` 提供；图标为**彩色色卡叠片**，颜色取自当前主题

## 5. UI 与文案规范

- 文案为**产品界面语言**：标签 ≤6 字，说明 ≤40 字，不用第一人称、不使用对话式解释、不出现"我们/咱俩/这一组存在的意义"等表达
- 控件样式：未激活项**无边框**（避免点击残留观感），激活项使用实心强调色；焦点环仅键盘触发
- 所有颜色取自当前配色 token，不硬编码

## 6. 安全不变式（硬约束，逐条有自动断言）

| 编号 | 不变式 | 断言位置 |
|---|---|---|
| S1 | 不订阅宿主的 `theme/change` 事件 | bundle 冒烟 |
| S2 | bundle 内不含 `setInterval`；默认状态不排任何定时器 | bundle 冒烟 |
| S3 | 每次激活只写 4 个 token 层，服务反复发事件也不增加 | bundle 冒烟 |
| S4 | 全屏覆盖层 ≤1，`z-index` = 1 | bundle 冒烟 |
| S5 | 颜色 token 内不得出现渐变/滤镜值 | bundle 冒烟 |
| S6 | 2 秒内 >24 次重绘即熔断，且只能手动解除 | 熔断单测 |
| S7 | 组件渲染异常被兜住，不影响宿主渲染树 | bundle 冒烟 |
| S8 | 插槽注册先于任何绘制逻辑，失败不导致入口消失 | 代码结构 + 冒烟 |
| S9 | 无深色模式：`dark` 槽位等同 `light` | WCAG 断言 |
| S10 | 卸载时清空全部层与样式表 | bundle 冒烟 |
| S11 | 单席位（`settings.launcher`）替换只在启用时注册、用更低优先级**遮蔽**而非抢占，停用即完全还原 | bundle 冒烟 |
| S12 | 状态持久化失败（配额/隐私模式）不静默：交给上层记为可见故障 | 状态层单测 |
| S13 | 插槽注册被拒不得向宿主抛出（回调内自兜） | bundle 冒烟 |
| S14 | **不做字体渐变**：正文渐变破坏行内 `code`，标题行渐变需改宿主 DOM（本插件不改 DOM） | 冒烟断言其不存在 |
| S15 | 会话标记只写声明式 CSS，不改宿主 DOM 结构 | bundle 冒烟 |

## 7. 技术方案

- **构建**：`build.mjs` 将 `src/` 拼接为浏览器唯一的 `client.js`，剥离测试专用 import/export
- **应用通道**：主通道为插件自有样式表（`!important` 写 CSS 变量）；`ctx.theme.overrideTokens` 为次通道，仅传合法颜色值，异常不中断
- **层模型**：`<pkg>`（10 个 alias） → `:accents`（派生 token，按档位裁剪） → `:finish`（效果 token） → `:workspace`（工作区强调色切片）
- **扩展点**：`settings.section`（完整面板页）、`sidebar.panellist` + `main`（工作台）、`conversation.composer.dock`（信号采集 + 可选状态条）、`shell.overlay`（帧顶工作区色条）、`sidebar.session.row.leading` + `sidebar.workspaces.session.menu.item`（会话标记）、`settings.launcher`（可选账号行，`priority: -1` 遮蔽官方行）
- **存储**：单一 key `dsh-theme-celadon.state.v3`；写入失败上报而非吞掉

## 9. 版本与发布

- 语义化版本；每个版本更新 `CHANGELOG.md`
- 破坏性变更（层模型、状态字段）升主版本
- 插件为 `link:` 安装：改代码即时生效，需刷新页面加载新构建

## 10. 已知限制

- 依赖宿主的 token 名称；宿主升级改名时对应效果会静默失效（诊断面板会显示"被拒值"计数）
- 侧栏工作区行无官方插槽，工作区标识以帧级色条实现
- 中文单选；无英文
- 「等待审批」状态的字段名未在宿主契约中确认，采用防御式探测，探测不到则不显示状态
- **头像走 localStorage**：整站配额约 5MB，浏览器多按 UTF-16 计费（1 字符 2 字节）。1MB 图片约 1.37M 字符，可能被计到约 2.7MB，因此 1MB 是上限而非推荐值；建议压到 200–400KB（如 256×256 PNG）。超过 700KB 数据 URL 时面板会提示
- 单席位账号行开启后**遮蔽**官方账号菜单：官方行的其余内容（若有）不保留；停用即完全还原
- 会话标记竖杠依赖 `sidebar.session.row.leading`，而官方只在**该行空闲**时挂载它：会话运行中竖杠可能不显示（工作台列表里始终可见）
- L4（真实界面自动化）验证在重启后执行，证据补进 `docs/TEST-REPORT.md`
