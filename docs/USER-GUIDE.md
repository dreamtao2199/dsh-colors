# 使用手册 · 多彩Harness

## 打开

* **设置 → 多彩Harness**：完整设置页，所有选项都在这里；
* **侧栏底部**：与「插件广场」并排的**多彩Harness**按钮 → **点一下＝随机一套**（鼠标悬停显示当前配色）；侧栏收窄成 56px 时只留图标。

> 0.9.10 起不再占用主导航（原来那个位置与设置页重复，已移除）。

## 逐项说明

### 配色库
22 套，全部仅浅色。点「官方原色」＝撤销全部覆盖、回到宿主默认。当前配色名、来源与两项对比度（正文/底、强调/底）显示在下方。

### 随机一套（308 种组合）
一次抽「配色 + 效果」。规则：

* 不会重复当前配色/效果（连点必换）；
* **锁配色 开** = 只换效果；**锁效果 开** = 只换配色；两把都锁 = 只重绘；
* 抽中的配色记为**手动优先**：领先到下一个时段边界，然后交还给十二时辰/间隔排程，**不会**关闭自动切换。

### 表面效果（14 种，单选）
与配色是**叠加**关系：换配色不丢效果，换效果不丢配色。再点一次当前项即取消（等于选「无」）。
*毛玻璃/渐变雾面*：通透与底色；*纤维/云絮/和纸/牛皮纸/亚麻/直纹纸/网点/扫描线*：128×128 无缝贴图平铺；
*硬描边/焦点描边/浮层投影/描金滚动条*：线条、焦点环、浮层阴影、滚动条。

### 作用范围
克制（5 项令牌）/ 标准（15）/ 张扬（20）。**不做字体渐变**（正文渐变会破坏行内代码显示，标题行渐变需要改宿主 DOM）。

### 自动切换
「关闭 / 1 小时 / 1 天 / 1 周 / 1 月 / 十二时辰」，前两者与十二时辰**互斥**。十二时辰四段（默认卯 05:00、巳 09:00、酉 17:00、亥 21:00），时刻与配色可改，**名称取该段的起始时辰**；「随机排程」给四段各抽一套不同配色。

### 手动优先
手动（含随机）选色后，面板会写「手动优先：<配色名>（到下一个时段边界交还排程）」。到点后自动回到排程，无需操作。

### 工作区配色
每个工作区可绑定一套配色：**仅强调色**（默认）或**整套**；未绑定则跟随全局。「全部跟随全局」一键清空。帧顶细线色条标识当前工作区（未检测到工作区时不显示）。

### 会话标记
给单个对话手选颜色（6 色，全部取自当前主题）→ 会话行首出现 3px 竖杠。入口两处：会话行「…」菜单、或工作台列表里逐条点选。**没标记的会话完全素净**。

### 账号行
昵称（≤24 字）与头像。头像流程：**上传 → 拖动/缩放 → 亮度/对比/饱和 → 确定**，输出统一 256×256。
默认**关闭**：关闭时官方账号入口（含快速退出登录）原样保留；开启后替换官方行，停用即还原。

### 安全与诊断
* **安全模式**：停用全部绘制（可随时恢复）；
* **还原出厂**：需要**点两次**（确认后执行）；
* **诊断**：期望值（本插件刚写入的值）vs DOM 实际读回值、生效来源、当前效果、标记数、重绘次数、服务失败/被拒值/全屏层/熔断状态，以及最近一次故障（「重新应用」可清故障并复位熔断）。

## 常见问题

| 现象 | 处理 |
|---|---|
| 界面没变化 | 确认配色不是「官方原色」；点「重新应用」；看诊断行「生效来源」 |
| 某个效果看不见 | 该效果可能依赖宿主消费位置（如浮层投影只作用于浮层）；换一个或看诊断「被拒值」 |
| 改了设置没保存 | 看诊断是否有「故障【storage】」（localStorage 配额满）；删除大体积头像 |
| 想完全回官方 | 安全模式 开，或「官方原色」＋「表面效果 无」 |
